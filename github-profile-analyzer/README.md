# GitHub Profile Analyzer

JavaScript project using the GitHub REST API.

## Features
- Search public GitHub users
- Profile, followers, following and repositories
- Total stars
- Top languages
- Popular repositories
- Responsive UI
- Error handling

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Stack
HTML5, CSS3, JavaScript (ES6+), Fetch API, GitHub REST API.
